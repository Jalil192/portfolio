# Portfolio personnel

Portfolio personnel développé pour présenter mes compétences, mes projets et mon parcours de manière professionnelle.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap
- GitHub Pages

## Date de réalisation

Novembre - Décembre 2024 (MAJ en MAI 2026)

## Présentation du projet

Ce projet est un portfolio personnel conçu pour servir de vitrine professionnelle.

Il permet de présenter :

- mon profil ;
- mes compétences techniques ;
- mes projets ;
- mon parcours académique ;
- mes expériences ;
- mes liens de contact.

Le site est entièrement responsive afin d’être consultable facilement sur ordinateur, tablette et mobile.

## Fonctionnalités principales

### Page d’accueil

La page d’accueil présente une introduction rapide, une photo de profil et une première mise en avant du profil.

### Section projets

Cette section présente plusieurs réalisations personnelles ou universitaires.  
Chaque projet est accompagné d’une courte description et, lorsque c’est possible, d’un lien vers le code ou une démonstration.

### Section compétences

Cette partie regroupe les principales technologies et outils utilisés, notamment en développement web.

### Section à propos

La section à propos permet de présenter mon parcours académique, mes expériences et mes centres d’intérêt.

### Section contact

Le portfolio contient une section contact avec un formulaire et des liens vers mes réseaux sociaux ou profils professionnels.

### Mode sombre

Un mode sombre a été ajouté afin d’améliorer l’expérience utilisateur et de proposer une interface plus confortable selon les préférences d’affichage.

## Objectif du projet

L’objectif principal était de créer une plateforme claire, moderne et responsive pour présenter mon identité professionnelle.

Ce projet m’a également permis de consolider mes compétences en développement web front-end, notamment sur :

- la structure HTML ;
- le responsive design ;
- la mise en page avec CSS, Flexbox et Grid ;
- l’utilisation de Bootstrap ;
- l’ajout d’interactions avec JavaScript ;
- le déploiement avec GitHub Pages.
