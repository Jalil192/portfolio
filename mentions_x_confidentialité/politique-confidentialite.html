Politique de confidentialité

Dernière mise à jour : 2026

Objectif de cette politique

Cette politique explique quelles informations peuvent être collectées lorsque vous utilisez ce portfolio personnel, notamment via le formulaire de contact.

Données collectées

Lorsque vous utilisez le formulaire de contact, les informations suivantes peuvent être transmises :

  • nom ;
  • prénom ;
  • adresse e-mail ;
  • contenu du message envoyé.

Finalité de la collecte

Les données envoyées via le formulaire sont utilisées uniquement pour répondre aux messages reçus et échanger dans un cadre professionnel, académique ou de recrutement.

Service utilisé pour le formulaire

Le formulaire de contact utilise Formspree, un service externe permettant de recevoir les messages envoyés depuis un site statique.

Les données saisies dans le formulaire sont donc transmises à Formspree afin de permettre l’acheminement du message.

Durée de conservation

Les messages reçus peuvent être conservés le temps nécessaire au traitement de la demande et aux échanges qui peuvent en découler.

Partage des données

Les données transmises via le formulaire ne sont pas vendues. Elles ne sont pas partagées avec des tiers, sauf si cela est nécessaire au fonctionnement du service utilisé pour l’envoi des messages.

Cookies

Ce portfolio ne met pas volontairement en place de cookies de suivi publicitaire ou analytique. Des services tiers, comme GitHub Pages ou Formspree, peuvent toutefois appliquer leurs propres règles techniques de fonctionnement.

Vos droits

Vous pouvez demander l’accès, la modification ou la suppression des informations que vous avez transmises via le formulaire de contact.

Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez utiliser le formulaire de contact disponible sur le portfolio.

Cette page est un modèle simple adapté à un portfolio personnel. Elle ne remplace pas un avis juridique.
